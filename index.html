Modellen (Holden)

Y = C + I + G + X − Q
Produksjon = samlet etterspørsel etter norske varer
C = zC + c₁(Y − T)
Konsum avhenger av disponibel inntekt
T = tY + zT
Nettoskatt; zT er skattenivået som ikke avhenger av inntekten
I = zI + b₁Y
Realinvesteringer øker med produksjonen
Q = aY
Import
G, X
Offentlig kjøp av varer og tjenester, og eksport, er eksogene

Tallene er for en tenkt økonomi og er valgt for å gi enkle regnestykker. Utgangspunktet er zC = 150, zI = 80, G = 350, X = 300 og zT = 0 (mrd. kr).

Løs oppgavene i rekkefølge. Knappen «Åpne i simulatoren» setter inn riktig sjokk og nullstiller parameterne til utgangspunktet (c₁ = 0,6, t = 0,3, b₁ = 0,1, a = 0,22). Regn gjerne ut svaret for hånd før du sjekker det.

Laget for MAO2100 Makroøkonomi. Modellen følger notasjonen i Holden, Makroøkonomi. Alle tall er i mrd. kr.
